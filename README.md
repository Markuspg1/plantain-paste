# PBP - Clipboard

A free, native macOS clipboard manager — a lightweight replacement for
subscription apps like Paste. Menu-bar app for macOS 13+, written in Swift
(AppKit + SwiftUI), built with plain `swift build` — no Xcode project needed.

The name nods to `pbcopy`/`pbpaste`: PBP is the pasteboard, remembered.

## Features

- **Clipboard history** for text, images, and copied files — captured
  automatically, persisted across restarts (up to 500 items).
- **⇧⌘V panel** — a bottom bar of horizontal cards. Type to search, arrow keys
  to navigate, **Return** to paste, **⌘1–9** quick paste, **⌘P** pin,
  **⌘⌫** delete, **Esc** to close. Click a card to paste it.
- **Paste in place** — with Accessibility access granted, choosing an item
  pastes it straight into the app you were using (the panel never steals your
  app's focus). Without it, the item is just copied and you press ⌘V yourself.
- **Pinning** — pinned items stay at the front and survive
  "Clear Unpinned History".
- **Privacy-aware** — skips anything marked transient/concealed (password
  managers like 1Password mark their copies this way), and dedupes repeats.
- **Launch at Login** toggle in the menu-bar menu.
- No accounts, no sync, no telemetry, no subscription. Your clipboard stays
  on your Mac.

## Build & install

Requires macOS 13+ and the Xcode Command Line Tools (`xcode-select --install`).

```bash
./make-app.sh --install
```

This builds `build/PBP.app` (ad-hoc signed), installs it to `/Applications`,
and launches it. (Plain `./make-app.sh` just builds.)

> **Why `--install` instead of dragging in Finder:** if your checkout lives in
> an iCloud-synced folder, moving the app out with Finder carries iCloud
> file-provider xattrs along, which invalidate the code signature — the app
> then shows up grayed out and won't launch. The install step strips the
> xattrs and re-signs at the destination. If you ever hit a grayed-out copy,
> fix it with
> `xattr -cr /Applications/PBP.app && codesign --force --sign - /Applications/PBP.app`.

After installing:

1. A clipboard icon appears in the menu bar.
2. On recent macOS versions, the first copy may trigger a **clipboard access**
   prompt — choose **Always Allow** (that's the whole point of a clipboard
   manager).
3. For paste-in-place, use the menu-bar item
   **Enable Auto-Paste (Accessibility)…** and add PBP in
   System Settings → Privacy & Security → Accessibility.
   (If you move or rebuild the app after granting, re-add it.)
4. Turn on **Launch at Login** from the menu.

During development you can also run the naked binary with `swift run`
(Launch at Login is disabled in that mode — it needs the .app bundle).

## Data

History lives in `~/Library/Application Support/PBP/`
(`history.json` + `images/`). Delete that folder to wipe everything.

## Uninstall

Quit from the menu bar, delete `/Applications/PBP.app`, delete the
Application Support folder above, and remove it from Accessibility settings.

## Notes & limitations (v1)

- Plain text only — rich text/RTF formatting is not preserved (pastes as
  plain text).
- The ⇧⌘V hotkey is fixed (defined in `Sources/PBP/HotkeyManager.swift`);
  note some apps use ⇧⌘V for "paste without formatting".
- Copied-file items store the file *paths*; if the original file is deleted,
  pasting that item won't work.
- The app icon is generated by `Support/generate-icon.swift`
  (`swift Support/generate-icon.swift master.png`, then rebuild the
  `.icns` with `iconutil`).
